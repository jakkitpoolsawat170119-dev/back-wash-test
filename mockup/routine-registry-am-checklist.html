— รายการ · — กลุ่ม

นำเข้าจากเอกสาร "AM List" 3 แผ่น (Line ต้ม 1 / Line ต้ม 2 / Line ต้ม 3) — กิจกรรมที่ทำขณะตรวจสอบประจำวัน Pro, CIP, NPP

สมมติฐานของ mockup นี้ — ขอยืนยันก่อนลงโค้ดจริง:
  • ใช้ช่อง "เครื่องจักร" เดิม (พิมพ์อิสระ ไม่ผูกตาราง) เป็นตัวจัดกลุ่มไลน์ → ชื่อที่เคาะแล้วคือ "Line ต้ม 1 / 2 / 3" (เอกสารกระดาษเขียนว่า "ถัง 1/2/3")
  • ช่อง "เป้าหมาย" เดิม = มาตรฐานการตรวจสอบ (ความหมายตรงกันอยู่แล้ว ไม่ต้องเพิ่มช่อง) · เพิ่มช่องใหม่ "วิธีการตรวจสอบ" 1 ช่อง (ต้องแก้ schema + API + ฟอร์ม)
  • ผู้รับผิดชอบหลักที่เคาะแล้ว = Maintenance (mt) — ทำให้ติ๊กบนกระดานเวรซ่อมบำรุงได้ทันที (ตอนร่าง mockup เคยเสนอ pd ไว้)
  • ความถี่ = ทุกวัน ตรงกับ "ตรวจสอบประจำวัน" ในหัวเอกสาร · ลำดับเดิม → sort order
✅ ข้อที่เคยค้าง — ตอบครบแล้ว (5 ก.ย.):
  • ชื่อไลน์ = "Line ต้ม 1/2/3" ⚠️ คนละอย่างกับ "Line 1/2/3" ของหน้า CIP (นั่นคือไลน์บรรจุ) — ตั้งชื่อชนกันไม่ได้ ในโค้ดจริงจึงใช้คำว่า "Line ต้ม" เต็ม ๆ
  • ผู้รับผิดชอบหลัก = Maintenance → งานทั้ง 45 ขึ้นให้ติ๊กบนกระดานเวรซ่อมบำรุงได้เลย ไม่ต้องรอสร้างกระดานฝั่งผลิต
  • แถวลำดับ 16 ของ Line ต้ม 2 ได้ข้อความจริงแล้ว: "ตรวจสอบการเดินตัวเปล่าของไฮเชียร์"
